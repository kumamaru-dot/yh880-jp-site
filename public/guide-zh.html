YH880 网站管理 · 操作手册

网站内容编辑操作指南

本指南说明如何通过管理后台修改 YH880 产品网站的内容。
无需编程知识，使用浏览器即可完成所有操作。

准备工作

开始前需要准备的事项

1
注册 GitHub 账号（如已有账号可跳过）
请访问 github.com 注册一个免费账号。
注册完成后，将您的 GitHub 用户名告知管理员（日本负责人），由管理员为您开通编辑权限。
2
确认收到 GitHub 协作者邀请邮件
管理员发出邀请后，您注册 GitHub 时使用的邮箱会收到邀请邮件。
请点击邮件中的链接，接受邀请。
⚠ 网络注意事项
GitHub 在中国大陆有时访问较慢或不稳定。如遇无法访问的情况，建议使用 VPN 后再操作。

第一步

进入管理后台

1
打开管理后台网址
在浏览器地址栏输入以下网址后按回车：
管理后台 https://musical-druid-7c9548.netlify.app/admin/
2
用 GitHub 账号登录
页面会显示 Sveltia CMS 的登录界面，点击「使用 GitHub 登录」按钮。
弹出的 GitHub 授权页面中，点击「Authorize（授权）」即可进入后台。
ℹ 登录后的界面说明
左侧菜单有两个栏目：「产品信息」（製品情報）和「产品特点」（製品の特長）。点击任意一项即可开始编辑。

第二步

编辑产品信息

目前共有三个产品条目：YH880-1、YH880-2、YH880-3。点击任意一个即可编辑。

1
点击左侧「製品情報（产品信息）」
右侧会显示产品列表，点击要编辑的产品名称（如 YH880-1）。
2
修改各字段内容
编辑界面包含以下字段：
字段名称说明
製品コード
产品编号		如 YH880-1（请勿修改）
製品名
产品名称		显示在网站上的产品名称（日文）
カテゴリ
类别/用途		产品面向的行业或用途
製品説明文
产品说明		产品的详细说明文字
使用用途
使用场景		以列表形式列出使用场景，可增删条目
製品画像
产品图片		点击可上传图片文件（JPG / PNG / SVG）
3
上传产品图片（如需更换）
点击「製品画像（产品图片）」字段中的上传按钮，从电脑中选择图片文件。
支持 JPG、PNG、SVG 格式。建议图片宽度在 800px 以上。
4
点击右上角「保存」按钮
编辑完成后，点击页面右上角的「保存」（保存）按钮提交修改。

第三步

编辑产品特点

1
点击左侧「製品の特長（产品特点）」
右侧会显示「9つの特長（九大特点）」，点击进入编辑界面。
2
修改各特点的文字
每条特点包含：特点名称（title）、数据/实绩（stat，可选）、说明文字（description）、备注（note，可选）。
直接在对应文本框中修改即可。
3
点击「保存」提交修改
完成后点击右上角的保存按钮。

保存后的流程

修改什么时候生效？

点击保存后，系统会自动处理发布，无需人工干预。全程约需 3～8 分钟。

✏️在后台保存管理后台
→
📦自动提交GitHub
→
⚙️自动构建3～8分钟
→
🌐正式发布glocal-action.com
正式网站 https://glocal-action.com/yh880/
ℹ 如何确认修改已生效
等待约 5 分钟后，刷新正式网站页面（按 Ctrl + F5）即可看到更新内容。
如果内容没有变化，请再等几分钟后重试。

注意事项

操作时的注意点

⚠ 请勿修改产品编号
「製品コード（产品编号）」字段（如 YH880-1）请不要修改，否则可能导致网站显示异常。
ℹ 操作无误但画面无反应时
如遇登录失败或页面空白，通常是网络问题。请检查 VPN 连接后刷新页面重试。
ℹ 图片上传建议
建议使用白色或透明背景的产品图片，格式推荐 PNG 或 SVG。
图片文件大小请控制在 2MB 以内，避免加载过慢。
